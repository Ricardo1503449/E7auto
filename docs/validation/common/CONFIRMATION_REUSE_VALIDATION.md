# 三帧联合确认与交接验证

日期：2026-11-05。用户在审查候选后授权“一并优化”。本批共19组，覆盖基准与
非基准的流程确认；没有改模板、ROI、识别门槛、匹配后端或自动战斗运动判定。
精灵之森入口原独立点击前确认的约定在本次授权内改为一次性交接。

## 实施范围

| # | 环节 | 当前处理 |
| --- | --- | --- |
| 1 | 企鹅每批购买前 | 祭坛状态保留最后购买/关闭控件，交给下一次购买或正常退出 |
| 2 | 企鹅进入森林、祭坛 | 到达确认一次性交接给入口点击 |
| 3 | 卡厄思介绍页、返回战斗页 | 复用已确认的进入按钮/战斗页标题 |
| 4 | 事件升阶入口和升阶页 | 入口结果交给点击，标题与目标英雄同步确认 |
| 5 | 修整进入升阶 | 消费营地已确认入口；全满分支联合确认离开 |
| 6 | 首领跳过招募券 | 已确认的继续探查按钮交给继续流程 |
| 7 | 武器库第二选项 | 关闭结果返回已稳定的第二选项，处理器不再独立等待 |
| 8 | 事件关闭后回地图 | 关闭模块确认原楼层地图后交给文本收尾和下一次选点 |
| 9 | 石板、通道 | 复用继续按钮，弃领提示与确认同帧累计 |
| 10 | 战斗准备 | 准备标题与开始按钮联合确认；换人后重新取证 |
| 11 | 招募、离队 | 招募标题/筛选入口、筛选关闭/指定英雄、离队标题/指定英雄联合确认 |
| 12 | 事件奖励卡、升阶结果 | 结果确认期间同步累计原600ms卡片稳定窗口；战斗升阶完成/继续同步确认 |
| 13 | 补给、节点商店 | 领取/购买结果与后续商品入口或离开控件同步确认 |
| 14 | 旅程结果页 | 旅程标题与关闭同步确认，后续大厅和日期观察保留 |
| 15 | 跨日首次关闭 | 日期标题和关闭同帧三帧后直接交给处理器，迟到关闭仍独立确认 |
| 16 | 企鹅正常返回 | 未变暗的页面控件和返回箭头联合确认，防止背景箭头授权 |
| 17 | 商店首次进店 | 同步商品完整性、停稳和身份计数，完整/部分有效证据交给顶部扫描 |
| 18 | 商店刷新重试 | 店内就绪和余额未变同帧确认，保留最后弹窗检查 |
| 19 | 商店最后底部商品 | 三帧已购按钮与店内就绪联合后省略重复等待；图标成功分支保留原确认 |

## 边界与实际验证

通用交接消费一次，截图、输入、恢复、窗口或transform变化后失效；Chaos同时绑定
本轮对象。仍使用最后一帧客户区坐标，原受控输入执行停止/窗口检查。只给明确列出
的控件建立交接，未通过完整联合三帧的后续控件回到原有确认。

本批按具体函数/参数分批运行pytest，没有运行完整套件。新增49个参数用例；既有
定向用例64个（其中森林重复确认期望、日期窗口异常注入点两例同步调整）。最终
113个不同用例通过。期间新增夹具的初始律荷完成键、非基准字典帧适配和仅识别
标题的断言已纠正；日期窗口异常按确认完成、输入之前的实际边界触发。

卡片从首次有效结果帧开始累计，正常稳定样本在7次100ms采样中达到600ms；内容
变化重新累计完整时长。商店新增进店用例实际保持三帧/200ms，完整证据不额外截图，
不完整首帧会继续补采；图标成功路径仍另做店内三帧确认。未减少成功结果门控，
也未把上一次输入之前的证据用于输入后的页面。

## 未验证范围

本批未操作真实游戏、未新录制截图、未进行新的图像正反例/尺寸回放或真实耗时
对比。原图匹配与阈值未变，复用既有图像验证。本次证明确认调度和守卫行为，
节省的实机时间仍待重新启动程序后验证；历史企鹅日志的0.368秒是改前重复等待，
不是本批优化后的测量结果。未构建、提交、推送或发布。
