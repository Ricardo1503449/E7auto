水晶存在时不点击；仅异常文字与重试文字同帧命中且无水晶时使用原重试坐标。
只读检测与执行恢复分开，拖动先释放；所有恢复出口重新取帧，保持原业务次数与待确认提交，不盲目重发。

## 2026-11-11 发布前缓存收尾修复

工作区审查发现bootstrap新建的公共网络候选缓存未被RuntimeSession收尾清理。使用真实network_retry模板只生成一个1536×864比例候选、不执行图像匹配，复现运行退出后仍保留20300字节；丢弃会话并执行GC后缓存持有者仍存活，显式clear后才释放。原因是候选终结回调持有缓存，而缓存仍持有候选；并非仅等待一次GC即可释放。

用户授权先处理该问题后，bootstrap向NetworkService显式注入缓存清理回调，RuntimeSession将公共网络缓存作为独立收尾步骤。业务缓存、网络缓存清理失败均不能跳过后续截图和日志关闭；启动通知失败同样执行收尾。未修改候选投影、评分、门槛、恢复状态机或任何正式资源。

本轮新增test_session_releases_production_network_candidates_and_cache_owner，实际验证运行退出后缓存计费归零、丢弃会话后持有者释放；既有test_initial_snapshot_failure_still_closes_session_resources扩展网络清理失败维度，覆盖8种启动/最终回调与两类清理异常组合。按这两个函数实际运行9例均通过，其中新增函数1例、扩展参数4例、复用既有参数4例；未运行整个测试文件或全套。
