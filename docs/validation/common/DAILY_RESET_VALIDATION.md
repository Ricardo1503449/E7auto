## 实现边界

共享runtime模块只处理日期关闭→签到确认→可选登录奖励关闭→稳定主界面；由调用方传入识别接口和就绪页面检测，不导入chaos、UI或平台实现。配置与ROI放config/internal.yaml的daily_reset块，仅显式消费者加载；卡厄思两队均要求全部五张资源，未接入的商店/企鹅不读取这些图片或配置。

关闭结算后同时识别日期标题和探查大厅；日期优先。首次稳定大厅启动2秒有效时间观察，重复大厅命中不重置计时。无有效页面最多等待15秒；进入日期处理后各阶段保持有界等待。所有点击要求连续稳定证据；签到确认只提交一次，日期/登录奖励关闭仅对同一稳定控件每隔至少1.5秒重试，总计最多3次。弹窗任一识别片段残留时，不接受其后方主界面作为完成。网络恢复暂停有效时间并打断识别连续性，但保留已点击状态和次数。

卡厄思成功/失败结算共用检查；成功只计一次、失败不计数。还有轮次时从稳定主界面复用入口导航，重新核对目标阶段；达到目标时不重新进入。大厅开始、阶段选择及最终返回动作前检查迟到日期弹窗，不在探查进行中安装全局拦截。
