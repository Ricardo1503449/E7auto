E7auto v1.1.4 x64 使用说明
============================

一、运行环境

1. 仅支持 Windows x64。
2. 无需安装 Python，也无需另外安装程序依赖。
3. 游戏进程名称必须为 EpicSeven.exe，游戏窗口标题必须为“第七史诗”。
4. 程序运行时需要 Windows 管理员权限。


二、首次使用

1. 从项目的 GitHub Releases 页面下载 E7auto_v1.1.4_x64.zip，并完整解压到
一个固定文件夹。
2. 不要直接在压缩包内运行，也不要只复制 E7auto.exe。
3. 启动《第七史诗》并完成登录，回到游戏主界面。
4. 双击 E7auto.exe。
5. Windows 弹出用户账户控制（UAC）时，确认程序来自可信来源后选择“是”。
6. 在“功能中心”点击“刷新秘密商店”卡片。
7. 在功能页输入本次允许消耗的天空石上限。
8. 如需购买友情点数，请点击“购买友情点数”右侧开关；圣约书签和神秘奖牌会始终购买。
9. 点击“启动脚本”。

游戏可以安装在任意磁盘或文件夹。程序会通过窗口标题“第七史诗”和进程名称
EpicSeven.exe 自动定位已经运行的游戏，不需要用户查找或填写安装路径。


三、运行时快捷键

F5：结束本次自动运行。

F6：暂停运行并进入悬浮窗移动模式。移动完成后再次按 F6，程序会保存悬浮窗
位置并继续运行。


四、界面说明

天空石上限：限制本次运行最多允许消耗的天空石数量。

购买友情点数：开关启用后，本次运行遇到友情点数商品时会进行购买。只有开关
本体响应点击，标签和所在行的空白区域不会改变状态。

主窗口支持自由缩放、最大化和还原。较窄时功能卡片改为单列滚动；卡片背景图
始终等比例覆盖并按固定视觉焦点裁剪，不会拉伸变形。

悬浮窗会显示运行时间、各类商品购买数量、已消耗天空石、连续未出货次数和
当前状态。


五、文件说明

E7auto.exe：程序启动文件。

config 文件夹：程序配置和校准数据，请勿删除或随意修改。

assets 文件夹：图像识别模板，请勿删除、改名或替换。

PySide6、cv2、numpy、yaml 等文件夹以及各类 DLL/PYD 文件：程序运行依赖，
请勿删除或单独移动 E7auto.exe。

logs 文件夹：程序运行后自动生成，保存文字运行日志，不保存游戏截图。
正式成品默认使用极简日志，仅保留启动/结束、购买和刷新成功、网络异常、输入失败及最终停止原因；不会记录识别轮询、坐标、置信度、性能和状态机过程。如需排查问题，可将 `config\internal.yaml` 中的 `logging.profile` 改为 `detailed` 后重新运行。


六、常见问题

1. 提示找不到游戏窗口

请确认游戏已经启动并登录，窗口标题为“第七史诗”，且 EpicSeven.exe 没有被
改名。不要同时启动多个符合条件的游戏窗口。

2. 点击开始后程序停止

程序采用安全停止策略。游戏窗口被最小化、失去前台焦点、尺寸调整失败、识别
结果不确定或输入验证失败时，程序会停止，避免错误点击。可在 logs 文件夹中
查看本次运行日志。

3. Windows 显示“未知发布者”或 SmartScreen 提示

当前版本没有数字签名。请只从项目 GitHub Releases 页面下载并运行完整压缩包。
不要关闭系统安全功能，也不要运行来源不明
的副本。

4. 是否可以只把 E7auto.exe 发给别人

不可以。E7auto.exe 依赖同目录中的配置、识别模板、DLL 和运行库。分发时必须
发送完整的 E7auto_v1.1.4_x64.zip；项目维护者通过 GitHub Releases 发布该文件，
不在源码仓库中保存本机构建目录或 ZIP。


七、注意事项

1. 当前识别和点击坐标以 2322 × 1306 游戏客户区为唯一校准基准。游戏所在
显示器的当前桌面分辨率不得低于 2560 × 1440。当前分辨率为 3120 × 2080 时，
程序使用原始 2322 × 1306 客户区；其他受支持分辨率会按完整显示器宽度的 60%
和固定宽高比调整窗口，完整窗口过高时会继续等比缩小。
2. 运行期间不要更换游戏所在显示器、修改 Windows 分辨率或显示缩放；检测到
显示器、分辨率或 DPI 变化时，程序会在下一次输入前停止。
3. 运行期间不要手动操作游戏、移动或最小化游戏窗口。
4. 请根据自己的实际需求设置合理的天空石上限。
5. 如需立即停止，按 F5。
