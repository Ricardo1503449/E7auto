# E7auto v1.4.29 x64 使用说明

E7auto 可以帮助你自动刷新秘密商店、批量购买企鹅，以及按预设策略运行卡厄思。本说明面向下载安装版的用户，无需编程或安装 Python。

**使用前请知悉：游戏自动化存在账号受限或封禁风险，程序无法保证账号安全。** 请先阅读文末的[使用风险](#使用风险)，再决定是否使用。

## 一、使用前准备

- 使用 Windows 64 位电脑。
- 游戏所在显示器的桌面分辨率至少为 **2560 × 1440**，可在 Windows 的“设置 → 系统 → 显示”中查看。
- 启动《第七史诗》并完成登录，建议回到游戏主界面后开始任务。不要同时打开多个游戏窗口。
- 确保拥有本次任务所需的天空石、金币、红叶，或可使用的卡厄思阶段和英雄。

程序会自动查找游戏，不需要填写游戏安装路径。开始任务时会调整游戏窗口大小；游戏已经最小化时，会先恢复窗口。

若当前页面未显示所选功能入口，但能识别右上角的四方框菜单（包括带通知点的图标），程序会尝试打开菜单、点击酒馆返回主界面，再进入所选功能。页面无法确认或返回失败时会停止，请手动回到主界面后重试。已经打开的侧边菜单或其他弹窗不保证可以自动处理。

运行过程中，游戏可以被其他软件覆盖，但请不要手动操作游戏、拖动或最小化游戏窗口，也不要更换显示器、分辨率或显示缩放。这些变化可能使任务停止。

## 二、安装并开始使用

1. 从[项目发布页](https://github.com/Ricardo1503449/E7auto/releases/latest)下载 Windows 安装包，本版本安装包名为 `E7auto_v1.4.29_Setup_x64.exe`。
2. 双击安装包，选择一个专门用于 E7auto 的空文件夹。不要选择磁盘根目录或游戏安装目录。按需要勾选“创建桌面快捷方式”。
3. 从开始菜单、桌面快捷方式，或安装目录中的 `E7auto.exe` 打开程序。
4. Windows 询问是否允许程序更改设备时，确认来源可信后选择“是”。程序需要管理员权限，选择“否”则不会启动。
5. 在“功能中心”选择要使用的功能，填好选项后点击 **“启动脚本”**。

出现“正在准备…”时请稍等，不要重复点击。启动成功后，主窗口会最小化，悬浮窗显示本次任务的进度。

同一时间只能运行一项功能。运行中不能切换功能；需要换任务时，先停止当前任务，再返回功能中心。

部分页面进入、选中、返回或关闭操作若首次点击没有响应，程序会在原目标仍稳定可见时自动补点一次。运行时请继续等待程序确认结果。

## 三、如何停止和查看进度

**停止方法：点击悬浮窗左上角“收起”下方的红色“停止”按钮。** 三项功能都使用这个按钮，F5 不能用于停止。

| 操作 | 使用方法 |
| --- | --- |
| 查看进度 | 悬浮窗会显示耗时、购买数量或完成轮数，以及当前状态 |
| 移动悬浮窗 | 直接拖动，松开后会记住位置 |
| 收起悬浮窗 | 点击绿色“收起”，变成圆形悬浮球 |
| 展开悬浮球 | 单击圆形图标；需要停止任务时，先展开再点“停止” |
| 隐藏已停止的悬浮窗 | 点击右上角关闭按钮，不会退出主程序 |

点击停止后，等待状态变为“已停止”，再操作游戏或关闭程序。手动停止或遇到异常时，程序可能停留在当前游戏页面，不会自动替你返回主界面。

再次启动任务时，新任务会重新计时和计数；建议先将游戏返回主界面。符合前述菜单识别条件的页面可以尝试自动返回，失败后请手动处理。

## 四、刷新秘密商店

在功能中心选择 **“刷新秘密商店”**，设置以下选项后点击“启动脚本”。

| 选项 | 含义 |
| --- | --- |
| 天空石消耗上限 | 本次允许用于刷新商店的天空石总量。例如填 `300`，表示刷新最多消耗300天空石；填 `0` 不执行刷新 |
| 购买友情点数 | 开启后购买遇到的友情点数商品；圣约书签和神秘奖牌始终属于购买目标 |
| 连续刷新 | 首次使用默认关闭，之后自动保存并恢复上次选择。开启后跳过转运等待，也不会因为连续49次未出货而结束；仍受预算、余额和停止条件限制 |

每次刷新消耗3天空石。天空石上限只控制刷新消耗，购买商品还需要游戏金币。剩余额度不足再刷新一次时，任务正常结束。

这两个开关需要点击开关本身，点击旁边文字不会切换。“连续刷新”切换后会自动保存，关闭程序后再次启动仍保留上次选择；保存失败会恢复原选择并在页面提示。“购买友情点数”仅在同一次打开程序期间保留，重启程序后恢复关闭。

### “转运ing...”是不是卡住了？

这是默认刷新模式中的正常等待。未开启“连续刷新”时，程序按 **13／13／13／10次** 分段刷新，阶段之间分别回主界面等待 **5秒／3分钟／5秒**，之后自动返回商店。

如果连续49次刷新都没有发现可购买的圣约书签或神秘奖牌，程序会正常结束，即使天空石预算尚未用完。发现其中任一种目标后会重新开始计算；友情点数不会重置这项计数。

等待期间无需手动进入商店，也无需重启程序，仍可随时点击悬浮窗“停止”。

正常结束时，程序会退出商店并返回游戏主界面。金币不足、购买结果无法确认等情况也可能提前结束任务，请根据提示或日志确认原因。

## 五、红叶换企鹅

1. 将游戏停在主界面，在功能中心选择 **“红叶换企鹅”**。
2. 填写 **“购买次数上限”**。一次购买50个企鹅计为1次；填 `0` 不购买。
3. 查看下方的“预计消耗红叶”，确认数量后点击“启动脚本”。

每次整批购买消耗5,100红叶。例如设置2次，预计购买100个企鹅、消耗10,200红叶。**预计消耗根据你填写的次数计算，不代表程序已经读到了你的实际红叶余额。**

程序会自动进入成长祭坛并购买。达到次数上限，或无法继续按5,100红叶购买整批时，会结束并返回主界面，不会购买零散数量或点击“购买货币”。

悬浮窗显示本次已购买次数。网络恢复后，程序会先确认上一笔购买结果；如果无法确认，会停止，不会直接重复购买。

## 六、自动卡厄思

1. 将游戏返回主界面，在功能中心选择 **“自动卡厄思”**。
2. 选择 **“目标阶段”**，支持第1至第5阶段，默认第1阶段。
3. 选择阵容，填写 **“完成轮数”**，然后点击“启动脚本”。轮数至少为1，默认1轮。

程序按内置路线、事件和战利品策略完成三层探查。目标阶段必须可用，所需英雄必须能在招募时找到；遇到无法识别的内容或无法确认的结果时会停止。

**启动进入探查大厅后，程序会自动放弃已有未完成探查并关闭结算，再按本次选择的阶段和阵容开始新探查。** 这次清理不计入完成轮数；如果希望保留并继续原来的探查，请勿启动此功能。

### 阵容怎么选？

| 阵容 | 初始成员 |
| --- | --- |
| 暗双子队（默认） | 里安娜路西艾拉、伊凡娜、小春、自由骑士雅洛薇 |
| 平民替换队 | 保健室老师律荷、伊凡娜、小春、暗影萝季 |

暗双子队会按内置流程在途中招募律荷，并替换雅洛薇。平民替换队不走这条中途换人流程。

升阶顺序为：暗双子队优先小春，再依次为里安娜路西艾拉、伊凡娜；平民替换队优先小春，再依次为暗影萝季、律荷。优先目标升满5阶后才轮到下一位。运行中不能更换所选阵容。

### 完成轮数怎么计算？

完成第三层、关闭整局结算并返回探查大厅后，才计为完成1轮。达到目标轮数后返回游戏主界面，显示“已完成”。

战斗失败不计入完成轮数；程序能确认返回大厅时会重新开局。因此，“完成轮数”不等于尝试次数，想提前结束请点击“停止”。

卡厄思不支持从中途继续。手动停止或异常停止后再次启动，会按上述规则清理旧探查并重新开局；当前页面无法自动返回时，需要先手动回到主界面。跨日运行时，程序会在每轮结束后处理能够识别的签到、登录奖励等提示，再继续下一轮。

## 七、设置与通知

点击侧边栏底部的齿轮进入“设置”。侧边栏只显示图标时，可点击左上角三横线展开文字。

| 设置项 | 用途 |
| --- | --- |
| 日志目录 | 打开本机运行记录，反馈问题时使用 |
| GitHub 项目地址 | 打开项目网页 |
| 检查更新 | 查询新版本，查看更新内容并更新安装版 |
| 运行结束通知 | 开启或关闭Windows通知，重启程序后保留选择 |
| 参与刷商店匿名统计 | 开启或关闭统计上传，查看待上传记录并重试 |
| 当前版本号 | 查看正在使用的版本 |

“运行结束通知”默认开启。正常完成、资源不足、异常停止或启动失败时会提醒；手动停止不提醒。通知声音和横幅受Windows通知、勿扰及音量设置影响。已出现的通知可以到Windows通知中心查看。

匿名统计默认开启，只对刷商店生效。上传随机运行编号、所用刷新策略、已确认的天空石消耗及两种商品购买次数，不上传账号、设备信息、日志或截图。网络不通时会保留待上传数据，之后自动补传；也可以在设置中点击“重新上传”。

关闭统计不会清空旧的待上传记录，重新开启后可以补传。统计上传失败不会改变商店购买计数或刷商店的停止条件。

在“关于”页面点击“使用说明”，可以再次打开本说明书。

## 八、检查更新与升级

程序会定期在后台检查更新，后台检查不会主动弹窗。设置齿轮和“检查更新”旁出现红点，表示已发现更高版本；查看更新内容后，红点也可能继续保留，直到完成升级或重新确认版本状态。

手动升级：

1. 先停止正在运行的任务，打开“设置 → 检查更新”。
2. 发现新版本后，阅读弹窗中的更新内容。较长的内容可以滚动；没有提供日志时会显示提示。
3. 点击 **“更新”**。程序会从GitHub下载安装包并显示进度，下载期间可取消。
4. 下载和校验完成后，按Windows管理员授权提示操作。安装器成功启动后，当前程序会退出，安装完成后自动重新打开。

覆盖升级会保留设置、悬浮窗位置、运行日志和统计记录。下载失败不会退出当前程序，可点击“重试更新”；取消管理员授权或无法启动安装器时，当前程序也会保留。

下载的安装包暂存在安装目录内，成功升级并启动后会自动清理，安装日志会保留。重新下载会从头开始。

暂时不更新时，点击“关闭”即可。普通结果弹窗也可按Esc关闭；需要键盘操作时，按Tab切换到按钮，再按回车或空格。

### 检查失败或没有提示新版本

- 普通网络失败可以点击“重试”。如果提示GitHub限制请求，请等待弹窗给出的时间后再试；重启程序不会清除等待时间。
- 游戏加速器能连接游戏，不代表一定能访问GitHub。
- 只有更高版本号才会触发更新提示。同版本号重新提供的安装包，需要从项目发布页下载后手动覆盖安装。
- 手动覆盖前先停止任务并关闭E7auto，再运行新安装包，保持原安装目录。**无需先卸载。**

自动下载安装适用于安装版；直接运行源码时不执行自动覆盖安装。

## 九、遇到问题时怎么办？

| 情况 | 建议处理 |
| --- | --- |
| 找不到游戏窗口 | 确认已启动电脑端游戏，窗口标题为“第七史诗”，没有同时打开多个游戏窗口；不要修改 `EpicSeven.exe` 的名称 |
| 提示分辨率不支持 | 检查游戏所在显示器的桌面分辨率是否达到2560 × 1440；调整后重新启动任务 |
| 点击启动后停止 | 查看功能页提示，确认游戏处于主界面、所选功能可用、所需文件完整；保留本次日志 |
| 显示“重连中” | 程序正在处理游戏网络异常，可等待恢复或点击“停止”；耗时继续累计属于正常显示 |
| 显示“已停止” | 本轮已经结束，可能是正常完成、手动停止或遇到异常；查看结束通知及日志确认原因 |
| 提示模板读取失败或 `Cannot load template` | 不要自行替换图片。确认安装文件未被删除，必要时使用官方安装包覆盖安装 |
| Windows提示“未知发布者” | 只从项目发布页获取安装包，确认来源；不要为了运行来源不明的文件关闭系统安全功能 |

反馈问题时，打开 **“设置 → 日志目录”**，保留发生问题那次运行的日志；如果有同一时间生成的图片，也一起提供。请说明使用的版本、功能、发生时间，以及此前做了什么操作。

日志会自动轮换清理，请及时保存需要反馈的记录。异常停止时可能保存一张游戏画面；分享前请自行检查其中是否包含不想公开的信息。正常完成和手动停止不会因此保存游戏截图。

## 十、文件保留与卸载

程序需要安装目录中的配套文件，**不要只移动或发送 `E7auto.exe`，也不要删除、改名或替换 `config`、`assets` 及其他运行文件。** 分享程序时，请提供官方安装包或发布页链接。

需要手动备份时，运行日志在安装目录的 `logs` 文件夹，设置和统计记录在 `state` 文件夹。先停止任务并关闭程序，再复制需要保留的数据。

普通升级应直接覆盖安装。**卸载会删除程序、设置、日志和统计记录**，因此不要通过“先卸载再安装”来进行保留数据的升级。

卸载可在Windows的“已安装的应用”或控制面板中进行，也可使用安装目录中的卸载程序。需要更换安装位置时，先备份需要的记录，再卸载并安装到新目录。

请自行阅读并遵守游戏服务条款、运营规则和所在地适用法律，自行决定是否使用。下载、测试或使用本程序，即表示你已知悉并自愿承担全部风险；因使用本程序导致的账号处罚、虚拟物品或货币损失以及其他相关损失，项目作者和贡献者不承担责任。如果不能接受这些风险，请勿使用。
